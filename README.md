# ORIENTEER
## What is the purpose of this application?
>Orienteer is a mobile application made for schools to encourage outside activity. It's goal is to provide tools for teachers to add tasks, keep an eye on your students and see task fulfillment for each student.
>It's firstmost goal is to provide features for teachers and the development of features for students comes second.

### What functions can teachers expect to have? How much is going to be done by the end of the prototype's life cycle?
>By the time the prototype is finished, the functions that teachers can expect are the following (in order of development priority):
- [x] Create assignments
- [x] Create Classes
- [x] Add grades (only in app for now, intended to work as more of a reminder than anything else)
### What functions are going to be added later on?
>The following functions are going to be developed as time allows and may or may not see the light of day by the time the project needs to be presented.
>They however should be fully implemented as of the 1.0 release.
>Their details may change as development progresses.
- [x] Account creation for teachers with proper authentication
- [x] Account creation for students with proper authentication
- [x] QR Code based class invitations for students
- [x] Students can submit photos as classwork
- [x] Optional location previews
- [x] Add additional teachers to one group
## Details about features mentioned prior.
- See the locations of their pupils:
  - A teacher should be able to see the location of each student.
  - They will not see who is who (at least at first, may change later.)
- Create assignments:
  - Add it to a group
  - Give it an initial endpoint (later should probably be able to add multiple)
  - Location based notifications & in-app popups.
- Create classes:
  - Add class name
- Add grades:
  - Ability to add a number based grade for each student
  - Grade feedback comment
  - Send notification when grade has been added and/or updated.
